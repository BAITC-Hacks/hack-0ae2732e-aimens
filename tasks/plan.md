# План доведения SanaLink до сдачи HackAlem AI

Цель: эксперт запускает проект по README, проходит весь кейс и проверяет каждое заявленное правило. Методика скрытого AI-оценщика неизвестна; основание для оценки — код, повторяемые проверки и точное описание. Устаревшие дизайн-документы не используются; текущий зелёный интерфейс сохраняется.

## Порядок и критерии готовности

| Шаг | Работа | Готово, когда |
| --- | --- | --- |
| 1 | Сверить кейс, официальный репозиторий, Git и организационные условия | Удаление старого дизайн-документа сохранено; изменения понятны; состав команды, активации и история работы не придуманы |
| 2 | Сделать локальные вопросы зависимыми от описания и карточки | Кофейня и курьеры получают разные вопросы; доступ к названным данным уточняется отдельно; пять вопросов по разным полям; повторный анализ учитывает ответы |
| 3 | Сохранить пять исходных черновиков в SQLite | Стабильные ID, тема и raw text, нулевой официальный рейтинг и NULL-датировки; команды их не видят; повторный seed сохраняет правки |
| 4 | Устранить дубли первого результата | Два выбранных предложения одной команды дают одну строку результатов; повторное подтверждение оставляет 10 баллов |
| 5 | Проверить изменённые пути и зафиксировать промежуточный результат | Адресные тесты, полный Vitest и typecheck проходят; реальный коммит отражает выполненную работу |
| 6 | Проверить внешний AI | Реальный синтетический запрос возвращает `openai`, 3–5 разных вопросов, проверенные источники; ошибка или тайм-аут включает явный локальный резерв |
| 7 | Проверить входы и полномочия деморолей | Неверные JSON, URL, роли, тело запроса, отклик на черновик и повторная награда корректно обработаны; ключ не отслеживается Git |
| 8 | Повторить запуск эксперта в чистой копии | На Node 24.x проходят ci/build/test/e2e/lint/typecheck; production без ключа проходит полный путь и сохраняет SQLite после перезапуска |
| 9 | Обновить README и доказательства | Матрица требований, версии, env, данные, AI-контракт и ограничения совпадают с кодом; результаты команд записаны по факту |
| 10 | Репетиция и сдача | Живое демо проходит за пять минут, клавиатура и ноутбук пригодны; финальная версия в `origin/main`; платформа показывает актуальное решение |

Приоритет при ограниченном времени: основной сценарий и уместность вопросов → чистый запуск → README → отправка. Внешний AI и визуальные улучшения не вытесняют сдачу. Не добавляются аутентификация, чат, файлы, календарь, векторная база или NVIDIA-интеграция.
