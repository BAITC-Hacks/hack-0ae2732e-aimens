# SanaLink — демонстрация за пять минут

## Подготовка

Запустите приложение по [README](../README.md). Для предсказуемого показа без интернета используйте `AI_MODE=local` либо оставьте API-ключ пустым. Откройте главную страницу. Под шапкой выберите «Бизнес»; конкретную команду по-прежнему можно выбрать в меню «Открыть профиль», селектор «Команда в профиле». Рядом с переключателем есть прямой вход в кабинет.

Все данные синтетические. Повторный показ создаёт новую задачу; сохранённые задачи и баллы предыдущего показа остаются в SQLite. Ссылки `example.com` демонстрируют поле ссылки, а не действующий прототип.

## 0:00–0:40 — слабое описание

На главной нажмите **«Разместить задачу»**. На этапе **«Черновик»** выберите пример кофейни либо введите:

> У нас сеть кофеен. Каждый вечер остаётся выпечка, и мы не понимаем, сколько готовить завтра.

Нажмите **«Помочь с описанием»**. На этапе **«Уточнение»** покажите минимум три разных вопроса и явную подпись локального помощника. Поясните: правила учитывают исходное описание и ответы в карточке; обращения к внешней модели в этом режиме нет. В кабинете бизнеса также доступны пять сохранённых исходных черновиков: они пока не видны командам и имеют официальный рейтинг 0.

## 0:40–2:00 — карточка, рост рейтинга и публикация

Ответьте на вопросы и нажмите **«Перейти к карточке»**. Все ответы остаются редактируемыми. Пример согласованной карточки:

| Поле | Синтетический ответ |
| --- | --- |
| Название | Снизить списания выпечки в сети кофеен |
| Тема | Торговля |
| Контекст | Каждый вечер остаётся непроданная выпечка |
| Потребность | Точнее планировать производство на завтра |
| Пользователи | Управляющие кофейнями |
| Данные и материалы | Таблица продаж и списаний за три месяца |
| Доступ к данным | Будут предоставлены |
| Ожидаемый результат | Прототип расчёта объёма выпечки на следующий день |
| Показатель успеха | Доля списанной выпечки |
| Целевое значение | Снизить на 20% на тестовой выборке |
| Ограничения | Только синтетические данные, без кассовых интеграций |
| Контакт бизнеса | demo@example.com |
| Взаимодействие | Консультация раз в неделю |
| Место работы | Удалённо |
| Навыки | Python, Аналитика, React |

Покажите прибавку **20** после указания данных вместе с доступом и **15** после заполнения показателя вместе с целью. Значение зависит от текущего заполнения; все девять критериев дают **100**. Место работы и навыки используются в каталоге и не меняют рейтинг.

Нажмите **«Предпросмотр»**. На четвёртом этапе **«Публикация»** проверьте карточку, отметьте checkbox «Я проверил(а) сведения…», нажмите **«Подтвердить карточку»**, затем **«Опубликовать задачу»**. Подтверждение и публикация — отдельные действия. Любая правка сбрасывает подтверждение и требует проверки заново.

## 2:00–2:40 — открытый каталог

Откройте **«Каталог задач»**, найдите задачу по словам из названия. Сортировка по умолчанию учитывает рейтинг, а при равенстве — более раннюю публикацию. Поэтому исходная задача кофейни со 100 баллами может находиться выше новой.

Покажите фильтры по теме, готовности и формату, сортировку, сохранение задачи в избранное и сброс фильтров. Все опубликованные карточки доступны каждой команде. Пример с низкой готовностью — Forma Studio, 20/100: он тоже принимает отклики.

## 2:40–3:30 — предложение команды

Вернитесь на созданную задачу и нажмите **«Студент»** — при первом переключении это **Qyran Lab**. Другую команду можно выбрать в меню профиля. Заполните форму предложения:

- **Идея:** прогноз спроса по истории продаж.
- **План:** изучить таблицу, собрать базовый прогноз, проверить с бизнесом.
- **Срок:** две недели.
- **Прототип:** `https://example.com/prototype`.

Отправьте предложение. Оно появится в кабинете команды и у бизнеса со статусом рассмотрения. Сам отклик баллов не даёт.

## 3:30–4:10 — решение бизнеса

Выберите профиль **«Бизнес»**. На карточке задачи рассмотрите идею, план и срок; нажмите **«Выбрать команду»** у предложения Qyran Lab. При нескольких предложениях появляется **«Сравнить предложения»** с таблицей идей, планов, сроков и навыков. Для отдельного показа сравнения можно открыть исходную задачу кофейни с несколькими демопредложениями.

Остальные предложения останутся на рассмотрении; бизнес может выбрать и вторую команду. Решение принимает человек. Выбор команды также не начисляет баллы.

## 4:10–5:00 — подтверждённый результат

В режиме **Qyran Lab** откройте задачу или кабинет команды, заполните «Что сделано» и ссылку `https://example.com/result`, затем отправьте первый результат. В режиме **«Бизнес»** подтвердите его кнопкой **«Подтвердить результат · +10»**. Покажите прирост **10 баллов** в кабинете команды.

Награда уникальна для пары «задача — команда». Повторный запрос подтверждения и несколько предложений этой команды не создают дополнительные баллы за этот первый результат. Во вкладке «Результаты» кабинета бизнеса пара отображается один раз.

До подтверждения команда может нажать **«Исправить результат»**, изменить описание или ссылку и сохранить. После подтверждения редактирование недоступно. Если сохранение прошло, но обновление списка не удалось, используйте **«Обновить данные»** в сообщении: повторно отправлять предложение не нужно.

## Дополнительная проверка перед показом

Это критерии репетиции, а не отметки о выполненных проверках:

- При поиске несуществующего текста появляется понятное пустое состояние и действие сброса.
- Избранное сохраняется после перезагрузки и относится к выбранному демопрофилю. Выбранный профиль восстанавливается в той же вкладке.
- Ошибка AI/HTTP оставляет описание и ответы в форме; доступно повторное действие.
- Незаполненные поля предложения и неправильная ссылка показывают ошибку.
- Предпросмотр и неподтверждённые правки не меняют публичную карточку.
- При закрытии и повторном запуске сервера задача, предложения, результаты и баллы сохраняются.
- На 1440 и 1280 px формы, карточки и навигация доступны без наложений; клавиатура даёт доступ к профилю и основным действиям.

## Ответы на вопросы жюри

- **Что показывает готовность?** Полноту подтверждённой карточки. Это не рейтинг компании и не проверка истинности.
- **Почему низкий рейтинг допускается?** Команда может помочь уточнить задачу; все опубликованные задачи открыты.
- **Что делает AI?** Извлекает подтверждаемые цитатами сведения и предлагает вопросы. Публикацию и выбор делает бизнес.
- **Что такое подборка для команды?** Совпадения интересов и навыков с пояснениями. Полный каталог доступен рядом.
- **Что сохраняется?** Карточки, предложения, решения и результаты — в SQLite; избранное — в браузере.
- **Что работает без интернета?** После установки зависимостей — весь основной путь с локальным помощником и локальными изображениями/шрифтами.
- **Проверена ли реальная модель?** Да, отдельный запрос на синтетическом описании доставки вернул режим `openai`, пять разных вопросов и значения с проверенными цитатами. Автоматические проверки ошибок используют подмену SDK; фактические результаты перечислены в README.
