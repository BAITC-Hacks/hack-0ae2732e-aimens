# Дизайн-система SanaLink

## Направление

SanaLink — площадка реальных задач бизнеса и студенческих команд. Интерфейс на русском, основной контекст — ноутбук и desktop 1280–1920 px. Визуальный ориентир marketplace переосмыслен через собственную композицию: компактная верхняя навигация, выразительная главная, категории, плотный каталог, рабочие формы и понятный рейтинг.

Эта версия заменяет прежнее направление «Практика» с синим акцентом. Источник значений — `src/app/tokens.css`; раскладка и состояния определены в стилях приложения. Существующие имена примитивов `--color-blue-*` сохранены для совместимости, но их значения теперь зелёные. Компоненты используют семантические токены.

## Типографика, сетка и интервалы

DM Sans поставляется локально через Fontsource; для недостающих символов — Segoe UI и системный sans-serif. Используются веса 400, 500, 600 и 700. Заголовки плотные, основной текст спокойный, числовой рейтинг заметен рядом с карточкой.

Основная шкала токенов: **12 / 14 / 16 / 20 / 24 / 32 / 40 / 56 px**. Верхний предел предназначен для заголовка главной; формы и каталог используют меньшие ступени. Длинные пояснения ограничиваются по ширине и не растягиваются на весь экран.

Шкала интервалов: **4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64 px**. Контент центрируется в общем контейнере. Главная использует две колонки в hero, каталог — фильтры рядом с сеткой карточек, редактор — основную форму и правую панель рейтинга. На меньшей ширине колонки последовательно складываются; сравнение предложений допускает прокрутку внутри таблицы.

Радиусы: **6 px** для компактных элементов, **12 px** для основных карточек/полей, **20 px** для крупных секций, pill — только для чипов и статусов. Тень карточки: `0 4px 16px #16332f08`, выпадающего профиля: `0 12px 36px #16332f18`. Основное разделение создают границы и поверхности.

## Компоненты

| Компонент | Поведение и визуальная иерархия |
| --- | --- |
| Навигация | Логотип SanaLink, главная, каталог, размещение, команды, описание платформы; активный маршрут обозначен |
| Профиль | Компактное раскрывающееся меню; `summary` с названием «Открыть профиль», селектор «Демопрофиль», переход в кабинет |
| Основная кнопка | Зелёная заливка, светлая надпись, одно основное действие в текущем контексте |
| Вторичная кнопка | Светлая поверхность и граница; назад, предпросмотр, редактирование |
| Поле | Постоянная подпись, подсказка рядом, видимый фокус и текст ошибки; placeholder не заменяет label |
| Карточка задачи | Компания, название, короткая потребность, тема/навыки, готовность, формат, переход и отдельная кнопка избранного |
| Избранное | Иконка закладки, `aria-pressed`, название с действием и названием задачи; сохраняется по демопрофилю |
| Категория | Единая линейная иконка, тема и количество; переход в отфильтрованный каталог |
| Рейтинг | Кольцо 0–100, числовое значение, название уровня, полосы критериев и конкретные подсказки «+N» |
| Предложение | Команда, университет/участники при наличии, навыки, идея, план, срок, ссылка и статус |
| Сравнение | Таблица нескольких предложений; решение «Выбрать»/«Отклонить» остаётся действием бизнеса |
| Пустое состояние | Локальная SVG, короткое объяснение и подходящее действие — например сброс фильтров |
| Сообщение | Успех через `role=status`, ошибка через `role=alert`, доступная кнопка закрытия |

Готовность группирует контекст и потребность в 20, данные и доступ в 20, результат в 15, показатель и цель в 15, ограничения в 10, пользователей в 10, контакт и взаимодействие в 10. В основе остаётся единая формула с девятью проверками. Название, тема, место работы и навыки на баллы не влияют.

## Состояния и движение

- **Hover:** умеренно меняются фон, граница или цвет; карточка сохраняет устойчивую геометрию.
- **Focus:** видимый контур у ссылок, кнопок, полей и профиля; доступен переход к основному содержимому.
- **Active/selected:** текущий фильтр, избранное и маршрут явно обозначены.
- **Loading/busy:** текст объясняет действие, повторная отправка блокируется, ввод остаётся на месте.
- **Error:** сообщение называет проблему и позволяет повторить действие без потери текста.
- **Empty:** отсутствие результатов объясняется в контексте фильтров; доступен сброс.
- **Unconfirmed:** редактор показывает предварительное значение; публикация требует отдельного подтверждения.

Изменение числа рейтинга занимает **200 мс**; `prefers-reduced-motion` отключает интерполяцию. Остальные переходы должны оставаться короткими, в диапазоне 120–250 мс для пользовательских действий. Декоративные бесконечные анимации, confetti и игровые медали не используются.

## Векторная графика и PNG

Оригиналы: `src/assets/svg/`, публичные копии: `public/assets/svg/`. Всего 30 файлов: логотип, логомарк, 20 интерфейсных иконок, шесть категорий, пустое состояние и hero. Иконки построены на сетке 24×24, имеют округлённые окончания и преимущественно толщину линии 1.7. Для цвета используется `currentColor`. При подключении внешнего SVG через `img` цвет задаётся самим файлом; для перекрашивания иконок подходит CSS mask или inline SVG.

Логомарк — два соединённых штриха в зелёном квадрате. Hero — оригинальная векторная сцена бизнеса и студентов у общей доски. Палитра иллюстрации поддерживает зелёный брендовый цвет, кремовые поверхности и тёплый терракотовый акцент. Встроенного растра, hotlinking и сторонних фотографий нет. Lucide используется как вспомогательный набор интерфейсных иконок.

`npm run assets:export` запускает `scripts/export-assets.mjs`: проверяет SVG, копирует источники и экспортирует Sharp в PNG 1× и 2×. Результаты: `public/assets/png/`, включая `hero-preview.png`. PNG не редактируются вручную: изменения делаются в SVG, после чего повторяется экспорт.

## Критерии проверки

Ниже критерии приёмки интерфейса; их наличие в документе не означает, что проверка уже выполнена:

- Главная, каталог, конструктор, карточка и кабинеты используют общие поверхности, типографику и действия.
- При ширине 1440 и 1280 px видны основные действия, ничего не перекрывает форму или рейтинг.
- Клавиатура позволяет открыть профиль, выбрать роль, пройти этапы и отправить форму; фокус видим.
- Масштабирование браузера и узкая ширина сохраняют чтение и доступ к действиям; таблицы прокручиваются внутри своей области.
- Обычный текст имеет достаточный контраст; статус понятен без цвета; кнопки с одной иконкой имеют доступное название.
- При уменьшенном движении рейтинг обновляется без анимированного счёта.
- Проверены длинные тексты, пустой каталог, загрузка, неверная ссылка, ошибка AI и повторное подтверждение.
- Работающий путь «описание → вопросы → подтверждение → публикация → отклик → выбор → результат → 10 баллов» сохраняется при визуальных изменениях.
