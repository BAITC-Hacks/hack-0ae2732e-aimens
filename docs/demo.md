# Демонстрация за пять минут

## Подготовка

Запустите приложение по README. Оставьте `AI_MODE=local` для предсказуемой демонстрации без аккаунта либо настройте реальный ключ. Откройте каталог в режиме «Бизнес». Состояние сохраняется в SQLite, поэтому повторный показ создаст новую задачу — это ожидаемо.

## 0:00–0:40 — потребность

«У бизнеса есть проблема, но ещё нет технического задания». Нажмите «Предложить задачу», выберите пример кофейни и «Помочь с описанием».

Покажите подпись локального/AI-помощника и вопросы. В локальном режиме честно поясните, что вопросы выбраны правилами приложения.

## 0:40–2:00 — карточка и рейтинг

Ответьте на вопросы коротко, затем «Перейти к карточке». Готовые синтетические ответы:

| Поле | Пример |
| --- | --- |
| Название | Снизить списания выпечки в сети кофеен |
| Контекст | Каждый вечер остаётся непроданная выпечка |
| Потребность | Точнее планировать производство на завтра |
| Пользователи | Управляющие кофейнями |
| Данные | Таблица продаж и списаний за три месяца |
| Доступ | Будут предоставлены |
| Результат | Прототип расчёта объёма выпечки на следующий день |
| Показатель | Доля списанной выпечки |
| Цель | Снизить на 20% на тестовой выборке |
| Ограничения | Только синтетические данные, без кассовых интеграций |
| Контакт | demo@example.com |
| Взаимодействие | Консультация раз в неделю |

Покажите прибавку 20 баллов после указания данных и доступа, 15 — после добавления показателя и цели. Подчеркните: баллы считает формула. Подтвердите сведения и опубликуйте. При всех полях рейтинг будет 100.

## 2:00–2:40 — открытый каталог

Вернитесь в каталог, покажите новую задачу и её позицию. У задачи кофейни из начальных данных тоже 100; она будет выше, поскольку опубликована раньше. Поставьте фильтр «Черновик»: задача Forma Studio с 20 баллами доступна всем и принимает отклики.

## 2:40–3:30 — предложение

Откройте новую задачу, переключитесь на Nomad Labs. Заполните:

- Идея: прогноз спроса по истории продаж.
- План: изучить таблицу, собрать базовый прогноз, проверить с бизнесом.
- Срок: две недели.
- Прототип: `https://example.com/prototype`.

Отправьте предложение. Это демонстрационная ссылка, не готовый проект.

## 3:30–4:10 — решение бизнеса

Переключитесь в «Бизнес», выберите команду. Другие предложения останутся на рассмотрении; при необходимости выберите вторую команду. Сам выбор не начисляет баллы.

## 4:10–5:00 — первый результат

В режиме Nomad Labs заполните «Что сделано» и `https://example.com/result`, отправьте результат. Вернитесь в «Бизнес» и нажмите «Подтвердить результат · +10». В кабинете команды покажите баланс. За эту же задачу повторной награды не будет.

## Ответы на вопросы

- **Зачем низкий рейтинг в каталоге?** Команда может помочь уточнить задачу; готовность и доступность независимы.
- **Проверяет ли AI правдивость?** Нет. Мы проверяем связь извлечения с исходным текстом, затем просим подтверждение человека.
- **Почему нет аккаунтов?** Это локальное демо двух сторон взаимодействия.
- **Что реально сохраняется?** Карточки, публикации, предложения, решения и подтверждённые этапы.
- **Что делать без интернета?** После установки зависимостей демо работает локально без ключа, шрифты и изображения из сети не нужны.
