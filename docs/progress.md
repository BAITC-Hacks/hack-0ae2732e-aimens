# Фактический прогресс SanaLink

23 сентября 2026 года объединены ветки `codex/sanalink-marketplace` и `codex/score-ai-hardening` поверх актуальной `main`. История обеих веток сохранена в Git. Почасовая история официального конкурса не имитируется.

## Что работает

- Главная и каталог с поиском, фильтрами, сортировкой, избранным, предпросмотром и объяснимыми рекомендациями.
- Конструктор из четырёх шагов: описание, 3–5 уточняющих вопросов, редактируемая карточка, ручное подтверждение и публикация. Низкий рейтинг не блокирует задачу.
- Рейтинг 0–100 с фиксированными весами, проверкой осмысленного текста, расшифровкой, тремя подсказками и расстоянием до следующего уровня.
- Отклики команд, сравнение предложений, независимый ручной выбор нескольких команд, первый результат и однократные 10 баллов после подтверждения бизнеса.
- Пять исходных примеров, пять опубликованных задач, пять команд и пять предложений. SQLite сохраняет пользовательские изменения между запусками.
- Предварительная оценка через API и финальный разбор карточки по содержанию перед публикацией; одноразовый токен не позволяет опубликовать версию, отличную от проанализированной.
- Подбор темы по описанию, 12 направлений, отдельное создание команды и десять казахских символов; профили бизнеса и создания команды разведены.
- Финальный разбор сохранён в SQLite и отображается в публичных карточках и каталоге; командные демопрофили получили новые названия и SVG-символы.
- OpenAI Responses API с проверкой цитат и локальным резервом. Повторяющиеся AI-вопросы устраняются. AI-запросы ограничены по размеру и частоте; режим и источник извлечённого значения отображаются в интерфейсе.
- Демопрофиль сохраняется на время вкладки в `sessionStorage`, избранное хранится в `localStorage`. Оба хранилища не заменяют серверную SQLite.
- 30 собственных SVG, 60 PNG 1×/2× и hero-preview, воспроизводимый экспорт через `npm run assets:export`.

## Проверки текущей версии

- `npm run typecheck`, `npm run lint`, `npm test` — успешно: **64 модульных теста в семи файлах**.
- `npm run test:e2e` — **13 браузерных сценариев**: полный бизнес-командный путь до +10 баллов, предварительная и финальная оценка, публикация при низкой оценке, создание отдельной команды, каталог, фильтры, избранное, смена профилей, сравнение и выбор команд.
- `npm run build` — успешно; собраны страницы, включая `/teams/new`, и API маршруты `/api/review-task` и `/api/suggest-topic`.
- Изолированная браузерная и процессная проверка не меняет рабочую базу `data/praktika.sqlite`.

Реальный запрос к OpenAI с платным ключом в этой доработке не выполнялся. Демо полностью проходит без ключа в явно обозначенном локальном режиме.
