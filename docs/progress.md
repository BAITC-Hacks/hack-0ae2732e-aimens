## Обновление SanaLink — 23 сентября 2026 года

Существующий рабочий путь переоформлен в marketplace SanaLink. Добавлены главная, отдельный каталог с поиском, фильтрами и предпросмотром, избранное по демокоманде, объяснимые рекомендации, четырёхшаговый конструктор, круговой рейтинг, сравнение предложений и меню профиля. Сохранены SQLite, ручной выбор нескольких команд и однократные 10 баллов за подтверждённый результат.

Созданы 30 оригинальных SVG, 60 PNG в размерах 1×/2× и отдельный hero-preview. Экспорт воспроизводится через `npm run assets:export`. Архитектура, AI-контракт, дизайн и демонстрация описаны в документах с именами `ARCHITECTURE.md`, `AI_PROMPT.md`, `DESIGN_SYSTEM.md`, `DEMO.md`.

Проверки обновлённой версии:

- Чистая установка `npm ci` в отдельной копии: успешно, аудит сообщил 0 уязвимостей.
- `npm run assets:export`, `npm run build`, `npm run lint`, `npm run typecheck`: успешно.
- `npm test`: **35 тестов прошли** в пяти файлах.
- `npm run test:e2e` с `PLAYWRIGHT_CHANNEL=msedge`: **12 сценариев прошли**, последний полный запуск — 55 секунд.
- Проверены низкорейтинговая публикация и отклик, сохранность ввода при ошибке анализа, повторное подтверждение после редактирования, поиск/фильтры/сортировка и оба сброса поиска, избранное по профилю, предпросмотр и рекомендации, выбор двух команд и отклонение третьей, полный путь до +10 баллов.
- В production отдельно пройден HTTP-сценарий «публикация с 0 баллов → предложение → выбор → первый результат → подтверждение». После остановки и запуска процесса с той же SQLite полный снимок данных совпал; повторное подтверждение не изменило баллы. Восемь основных страниц ответили HTTP 200.
- Вручную в браузере проверены навигация, поиск, фильтры, избранное, смена роли, локальные вопросы и перенос ответов в карточку с изменением предварительного рейтинга 10 → 65. На главной все 16 изображений загрузились. Ошибок в консоли проверенных страниц нет; после предварительной загрузки маршрутов production-браузер сообщил одно предупреждение о неиспользованном CSS preload.
- Осмотрены desktop-экраны 1440/1280 px; главная не имеет горизонтального переполнения на 390 px, каталог дополнительно проверен E2E на 320 px.

Production-версия запущена командой `npm start -- --port 3201` с локальным AI. Рабочая база — `data/praktika.sqlite`; проверки записи использовали отдельные временные базы. Реальный OpenAI-запрос с ключом не выполнялся.

## Проверки исходной версии до SanaLink

- Чистая установка `npm ci`: успешно; аудит зависимостей сообщил 0 уязвимостей.
- `npm run build`: собраны все маршруты.
- `npm run lint`: без ошибок и предупреждений.
- `npm run typecheck`: успешно.
- `npm test`: **28 тестов прошли** в четырёх файлах.
- `npm run test:e2e` с `PLAYWRIGHT_CHANNEL=msedge`: **3 сценария прошли** на отдельном сервере и временной базе.
- Первый E2E: создание, вопросы, полный рейтинг, публикация, проверка несохранённых правок, отклик, выбор, первый результат, подтверждение и 10 баллов.
- Второй E2E: страницы, фильтры, смена роли, доступ к карточке с 20 баллами.
- Третий E2E: названия мобильной навигации, видимый фокус и отсутствие переполнения на 320 и 1030 px.
- Сохранность: тест закрывает файловую SQLite и открывает её заново, сравнивая задачи, предложения, решения, прогресс и баланс.
- В браузере осмотрены каталог, конструктор, карточка, кабинеты, список команд и гид; собранная версия запускается через `npm start`.

Реальный OpenAI-запрос с платным ключом не выполнялся. Контракт, проверка цитат и резерв при отказах проверены отдельно; демо полностью проходит без ключа.
