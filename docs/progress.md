# Фактический прогресс SanaLink

## Доработка 23 сентября, 16:18 (UTC+5)

- Локальный анализ учитывает исходный текст и ответы: явно названные данные и числовая цель меняют вопросы; неизвестный доступ уточняется отдельно. Поля не заполняются догадками.
- Пять исходных описаний сохраняются как отдельные неподтверждённые черновики SQLite. Повторная инициализация сохраняет правки.
- Результаты в кабинете уникальны для пары «задача — команда», включая несколько выбранных предложений одной команды.
- Проверка источников AI исключает служебные значения enum; промпт различает консультации бизнеса и взаимодействие пользователя с системой.
- В рабочей копии прошли 69 модульных тестов и typecheck; шесть адресных E2E прошли в Edge. В чистой копии повторно прошли 69 тестов; полный браузерный прогон продолжается.
- Два реальных запроса OpenAI на синтетическом описании доставки вернули `openai`, пять различных вопросов и дословно подтверждённые извлечения. Модель `gpt-4.1-mini-2025-04-14`, ключ только в игнорируемом серверном окружении.
- В отдельной папке прошли `npm ci`, сборка, lint и новая команда `npm run test:production`: новый процесс без ключа, весь путь до 10 баллов, остановка, повторный запуск и неизменный снимок SQLite. Финальный прогон после двух последних AI-регрессий выполняется отдельно.
- На платформе проверены выбранный трек «Образование», кейс AI Sana и совпадение выданного репозитория с `origin`. Форма решения пока не отправлена.

23 сентября 2026 года объединены ветки `codex/sanalink-marketplace` и `codex/score-ai-hardening` поверх актуальной `main`. История обеих веток сохранена в Git. Почасовая история официального конкурса не имитируется.

## Что работает

- Главная и каталог с поиском, фильтрами, сортировкой, избранным, предпросмотром и объяснимыми рекомендациями.
- Конструктор из четырёх шагов: описание, 3–5 уточняющих вопросов, редактируемая карточка, ручное подтверждение и публикация. Низкий рейтинг не блокирует задачу.
- Рейтинг 0–100 с фиксированными весами, проверкой осмысленного текста, расшифровкой, тремя подсказками и расстоянием до следующего уровня.
- Отклики команд, сравнение предложений, независимый ручной выбор нескольких команд, первый результат и однократные 10 баллов после подтверждения бизнеса.
- Пять исходных примеров, пять опубликованных задач, пять команд и пять предложений. SQLite сохраняет пользовательские изменения между запусками.
- OpenAI Responses API с проверкой цитат и локальным резервом. Повторяющиеся AI-вопросы устраняются. AI-запросы ограничены по размеру и частоте; режим и источник извлечённого значения отображаются в интерфейсе.
- Демопрофиль сохраняется на время вкладки в `sessionStorage`, избранное хранится в `localStorage`. Оба хранилища не заменяют серверную SQLite.
- 30 собственных SVG, 60 PNG 1×/2× и hero-preview, воспроизводимый экспорт через `npm run assets:export`.

## Проверки объединённой версии

- `npm run typecheck`, `npm run lint`, `npm test` — успешно: **58 модульных тестов в шести файлах**.
- `npm run test:e2e` с установленным Edge — **12 браузерных сценариев прошли**. Они проверяют полный путь до подтверждения результата и +10, низкий рейтинг, сохранность ввода при ошибке AI, каталог, избранное, смену и восстановление роли, сравнение и выбор двух команд.
- `npm run build` — все маршруты собраны. Отдельно проверен рабочий вариант SanaLink: чистая установка `npm ci`, процессный перезапуск с той же SQLite и сохранение задачи, отклика, решения и результата. Эти проверки проводились до объединения; после него повторно выполнены сборка и сценарии выше.
- Изолированная браузерная и процессная проверка не меняет рабочую базу `data/praktika.sqlite`.

Реальный запрос к OpenAI с платным ключом в объединённой версии не выполнялся. Демо полностью проходит без ключа в явно обозначенном локальном режиме.
