# Задача и границы MVP

**Пользователи:** бизнес с нечётко описанной потребностью и студенческие команды, которым нужна практика.

**Ценность:** структурированная карточка делает задачу понятной, прозрачный рейтинг подсказывает, что дополнить, открытые предложения оставляют выбор исполнителей бизнесу.

**Основной путь:** описание → 3–5 вопросов → редактирование → подтверждение → рейтинг → публикация → предложение команды → ручной выбор → первый результат → подтверждение → 10 баллов.

## Обязательные страницы

Каталог; конструктор; карточка и редактирование; кабинет бизнеса. В демо также есть кабинет команды, список пяти команд и гид, чтобы можно было пройти обе стороны сценария без аккаунтов.

## Принятые решения

- Next.js, TypeScript, Tailwind CSS, Zod, локальная SQLite через Node.js 24.
- OpenAI Responses API со структурированным ответом и локальным резервом.
- Детерминированный рейтинг; полнота сведений, а не проверка их истинности.
- Публикация с любым рейтингом после ручного подтверждения.
- Неограниченные отклики; можно выбрать несколько команд, отклонить все либо пока никого не выбирать.
- Единственный этап «Первый результат»; 10 баллов за подтверждение один раз на задачу и команду. Размер награды — решение MVP, не заданная в кейсе цифра.
- Синтетические данные и переключение ролей без регистрации.

## Приоритеты и оценивание

Сквозной путь, качество карточки и прозрачность рейтинга составляют 60/100 по шкале пользовательского плана кейса. Локальный документ `Правила оценивания.docx` отдельно описывает техническую оценку проекта: соответствие кейсу 20, реализация 25, README 20, воспроизводимость 20, надёжность и безопасность 15. Эти баллы не являются рейтингом задач.

## Вне объёма

Регистрация, реальные аккаунты, чат, уведомления, файлы, рекомендации, календарь, сложный трекер этапов, обучение моделей и производственное размещение.
