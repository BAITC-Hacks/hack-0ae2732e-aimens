# Сторонние компоненты и источники

Версии и лицензии ниже прочитаны из установленных пакетов. Точные зависимости зафиксированы в `package-lock.json`.

| Компонент              | Версия | Лицензия            | Использование                     |
| ---------------------- | ------ | ------------------- | --------------------------------- |
| Next.js                | 16.3.6 | MIT                 | Маршрутизация, сервер и сборка    |
| React / React DOM      | 19.3.0 | MIT                 | Интерфейс                         |
| Tailwind CSS           | 4.3.3  | MIT                 | CSS-инструментарий                |
| Zod                    | 4.6.5  | MIT                 | Проверка входов и AI-ответов      |

| Lucide React           | 1.47.0 | ISC                 | Иконки                            |
| Vitest                 | 5.0.1  | MIT                 | Unit и интеграционные тесты       |
| Playwright Test        | 1.63.0 | Apache-2.0          | Сквозные тесты                    |
| Prettier               | 3.9.9  | MIT                 | Форматирование исходников         |
| DM Sans via Fontsource | 5.3.0  | SIL OFL 1.1 (шрифт) | Локально подключённая типографика |

Node.js 24 предоставляет `node:sqlite`; отдельный ORM или пакет SQLite не используется. ESLint и TypeScript используются для проверки кода. DM Sans поставляется с приложением, без сетевой загрузки шрифта в браузере. Внешние изображения, платные шаблоны и библиотеки компонентов не загружались.

## Модель

OpenAI `gpt-4.1-mini-2025-04-14`, серверная настройка `OPENAI_MODEL`. Вызовы регулируются условиями OpenAI и требуют отдельного ключа; сам SDK не предоставляет бесплатный доступ к модели. Демо без ключа работает локально. Использование живого API в текущей сессии не проверялось.

## Материалы требований

- [Кейс AI Sana](https://docs.google.com/document/d/1lFWekP2SirFarATKkWa5neHNL5DlhjZKkUacvGyZk8k/edit).
- [Страница HackAlem](https://edu.astanahub.com/hackathons/df4743f5-c492-415c-b45a-1f13adb78e06?tab=tracks).
- Локальный `Правила оценивания.docx`: шкала технического отбора и Demo Day.
- [Riipen](https://www.riipen.com/): ориентир по структуре платформы практического обучения. Указание «e-commerce storefront» в предоставленном извлечении не соответствует продукту и не переносится в демо.
- Предоставленное описание Powered by HackAlem: ориентир по типографике, токенам и критериям доступности. Вывод извлечения о «documentation site» не принят для этого приложения. Реализованные правила записаны в `design.md`.
- `HACKALEM_STRUCTURE.md`: предварительно подготовленный организационный контекст.

## Данные и оригинальный код

Данные в `src/domain/demo-data.ts` и начальные предложения синтетические, внешние датасеты не использовались. Адреса `example.com` — демонстрационные. Исходники приложения написаны для этого локального прототипа с помощью Codex. Код не заявляется как созданный внутри официального времени соревнования; перенос в конкурсный репозиторий регулируется правилами организатора.
