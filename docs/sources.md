## Модель

OpenAI `gpt-4.1-mini-2025-04-14`, серверная настройка `OPENAI_MODEL`. Вызовы регулируются условиями OpenAI и требуют отдельного ключа; сам SDK не предоставляет бесплатный доступ к модели. Демо без ключа работает локально. Использование живого API в текущей сессии не проверялось.

- `HACKALEM_STRUCTURE.md`: предварительно подготовленный организационный контекст.

## Данные и оригинальный код

Данные в `src/domain/demo-data.ts` и начальные предложения синтетические, внешние датасеты не использовались. Адреса `example.com` — демонстрационные. Исходники приложения написаны для этого локального прототипа с помощью Codex. Код не заявляется как созданный внутри официального времени соревнования; перенос в конкурсный репозиторий регулируется правилами организатора.
