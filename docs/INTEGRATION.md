## Решения при разрешении конфликтов

- Официальная готовность всегда рассчитывается `computeReadiness` с исходными весами и уровнями. Эвристическая оценка содержания не заменяет её.
- AI-разбор не становится условием публикации. Название, тема и подтверждение пользователя достаточны; низкий рейтинг не препятствует откликам.
- Сохранены пять исходных черновиков, идемпотентные демоданные, SQLite между перезапусками и уникальная награда за результат.
- Сохранены отмена анализа, редактируемые ответы, проверка цитат и защита интерфейса от запоздалых запросов при смене роли.
- Созданная пользователем команда может сразу отправлять предложения; ошибка обновления предыдущего профиля не отменяет успешное создание.
- Перевод не меняет значения темы, ввод пользователя и идентичность команды. Русский язык остаётся исходным; перевод новых текстов зависит от словарей.
- Существующая зелёная палитра сохранена согласно AGENTS.md.
- README и примеры запуска переведены на итоговую `main`; исторические ветки сохраняются.

Включены также последние изменения README из `e62c9ca` и `41346a2`: описание пользы, создание собственной команды и три языка. Итоговый README сохраняет структуру для жюри и отражает фактические правила объединённой реализации.

## Проверка чистой копии

Исходники выгружены из Git в отдельный временный каталог, без `.env.local`, ключей, `node_modules` и рабочей SQLite. Версии: Node.js 24.18.0, npm 11.17.0. Исходники, скрипты и тесты сверены с итоговым рабочим деревом.

- `npm ci` — успешно, зависимости установлены по lockfile.
- `npm test` — 87/87, 12 файлов.
- `npm run test:e2e` — 38/38, Chromium, около 2 минут. Проверены новые команды, RU/KK/EN, сохранность текста при переводе, AI-кнопки, каталог, роли, подтверждение и баллы.
- `npm run build`, `npm run typecheck`, `npm run lint` — успешно.
- `npm run test:production` — полный HTTP-путь без ключа, публикация и отклик при 0, отдельное сохранение рекомендаций без изменения готовности, сохранность SQLite после реального перезапуска и ровно 10 баллов при повторном подтверждении.

В промежуточном браузерном прогоне исправлены селекторы закрытого меню профиля, поля поиска и темы. Итоговый полный прогон выполнен после исправлений. Новые зависимости не добавлялись; lockfile сохранён. Внешний OpenAI при финальном прогоне не вызывался.
